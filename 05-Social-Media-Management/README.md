# 📱 Social Media Management System

## 📖 Overview

This project demonstrates a Social Media Management System built using C#. It allows users to create posts, like posts, manage unique users, generate notifications, and maintain an action history using various C# collection classes.

## 🧠 Concepts Covered

- List<T>
- Dictionary<TKey, TValue>
- HashSet<T>
- Queue<T>
- Stack<T>
- CRUD Operations
- Undo Functionality

## ⚙️ Features

- Add unique users
- Create social media posts
- Like posts
- Undo the last action
- Manage notifications using Queue
- Store unique users using HashSet
- Maintain action history using Stack
- Track likes using Dictionary
