
# 🛒 E-Commerce Order Management System

## 📖 Overview

This project demonstrates the implementation of an E-Commerce Order Management System using C#. It manages customers, orders, categories, order processing, and order history by utilizing various C# collection classes.

## 🧠 Concepts Covered

- Classes & Objects
- List<T>
- Dictionary<TKey, TValue>
- HashSet<T>
- Queue<T>
- Stack<T>
- CRUD Operations

## ⚙️ Features

- Add customer information
- Create multiple orders
- Update order prices
- Remove existing orders
- Process orders using Queue
- Track order status using Stack
- Store unique categories using HashSet
- Manage customers using Dictionary

## 🎯 Learning Outcome

- Applied multiple C# collection classes in a real-world scenario.
- Learned how to organize and manage data efficiently.
- Practiced CRUD operations using collection classes.
- Improved understanding of queue-based processing and stack-based history tracking.
